# Standalone secrets extraction: implementation checklist

Tracking: [PHNX-3989](https://linear.app/getrush/issue/PHNX-3989) delivers the plan only. [Proposal](proposal.html) · [Delta spec](delta-spec.md). All boxes below are proposed implementation, not completed work. Future implementation should claim its tracker item when delivery starts.

1. [ ] **Pin and test the contract.** New standalone repository: `src/schema.ts`, `src/protocol.ts`, `src/context.ts`, adjacent tests and `testdata/`. Define YAML/JSON v1, capability errors, private transport framing, opaque scopes, policy and expiry rules. Audit every path in `inventory.json`, shell references and `cli/src/lib/resources.ts`. Verify unknown provider/version, duplicate key, cyclic bootstrap and invalid environment values fail before any child starts.
2. [ ] **Extract local storage and the bundle engine.** Move `cli/src/lib/secrets/{index,bundles,filestore,linux,windows,vault,vault-age-helper,lease,session-store,scope,read-backoff,headless,rc-hygiene,list-filter}.ts` into standalone `src/{core,stores,providers}/`; carry remaining dependency closure and meaningful adjacent tests. Pull raw profile-item primitives into public SDK/internal process operations. Replace state/resource/feed imports with explicit configuration and callbacks. New CLI `src/cli.ts` owns commands currently in `cli/src/commands/secrets*.ts`; no agents executable on its PATH during the standalone smoke.
3. [ ] **Move the broker and helper ownership.** Extract `agent.ts`, `reaper.ts`, `sync-commands.ts`, `install-helper.ts`, `download-keychain.ts`, `keychain-helper.swift`, necessary helper install/download primitives and release inputs. Keep signing identity, entitlement and service identifiers. Standalone `src/broker/` owns start/stop, version negotiation and exactly one socket owner. Real macOS grant expiry, human unlock, timeout/reap and restart tests must pass. Broker startup cannot import or execute agents-cli.
4. [ ] **Implement cloud references.** Extend/move `cli/src/lib/onepassword.ts` into standalone `src/providers/onepassword.ts`; add `src/providers/aws-secrets-manager.ts`. Reuse native authentication, official AWS SDK credential chain and vendor reference semantics. Use bounded argv-based calls for op, no arbitrary shell exec. Cloud mutation is unsupported initially and returns explicit capability errors. Run real disposable-item tests for auth, rotation, missing field, per-invocation freshness, no plaintext diagnostics and all-or-nothing injection.
5. [ ] **Extract transport without fleet policy.** Refactor `cli/src/lib/secrets/{remote,push,sync,sync-backend}.ts` into standalone optional `src/transports/ssh.ts` and `src/sync/`. OpenSSH alias resolution only; strict pinned-host behavior, no multiplexed secret channel, deadlines and platform-aware remote invocation. Define `--from` versus `--to`; versioned request carries key/expiry policy. Keep managed-service auth in an optional driver derived from `drivers/rush.ts`. Prove remote resolution/local execution and remote execution as distinct real-host flows. Test destination read-back, wrong peer version, unavailable host and destination rejection; reject remote GIT_*, *_PROXY, *_BASE_URL and loader/interpreter variables.
6. [ ] **Convert agents consumers and remove engine imports.** Add `cli/src/lib/secrets-client.ts` as the one client. Convert `commands/exec.ts`, `commands/browser.ts`, `commands/accounts.ts`, `commands/ssh.ts`, `lib/account-registry.ts`, `lib/profiles.ts`, `lib/browser/chrome.ts`, `lib/share/config.ts`, `lib/exec.ts` and every direct/transitive consumer from inventory. Convert sync raw callers to async where practical; any necessary synchronous process client must be bounded and cannot load the old engine. Keep fleet policy from `reserved-sync.ts`, resource selection and account role rules in agents-owned modules. Remove hosting from `lib/daemon/{secrets-broker-service,keychain-reap-service,daemon}.ts`; change `index.ts` hidden helpers and bootstrap registration. Read the daemon AGENTS.md before implementation.
7. [ ] **Cut over stores and command references.** New standalone `src/migrate.ts` and adjacent real-store tests inventory/adopt native items and explicitly import encrypted file/age state. No automatic deletion/dual writes. Preserve bundle reveal refusal under neutral and existing agent context signals or noninteractive execution, with the narrow raw-item exception. Update `cli/src/commands/setup-secrets.ts`, `cli/src/lib/resources.ts`, `cli/scripts/`, tracked secrets skills/hooks/resources, `cli/docs/{secrets,specifications,credential-management}.md`, README and component AGENTS.md. Map raw item IDs, metadata, profiles, grant scope and encryption settings. Retire `agents secrets`, old self-exec verbs and engine files only once all consumers and release scripts use the new command/client.
8. [ ] **Publish, install, measure and demonstrate.** Independent repo gets canonical `scripts/{build,test,install,release}.sh` and isolated helper release. Define optional CLI acquisition/update and supported protocol range through agents' existing external-CLI conventions; fail with installation guidance if unavailable, no silent old-engine fallback. Verify packed agents tarball excludes engine/provider/helper code. Follow agents release scripts without helper rebuilding and preserve auto-update. Run installed standalone with agents absent, then installed agents consumer matrix plus real remote-source/local-child flow. Capture value-free terminal evidence and the paired versions. Rollback test must account for any post-cutover writes.
