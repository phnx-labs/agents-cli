- **`agents traces sync` now reports recover-then-succeed runs as `completed` while still surfacing the tool failures (PHNX-3387).** Previously `meta.outcome` was derived from `errorCount > 0`, so any session that hit a tool error and then recovered was mislabeled `errored`. A run whose final tool step succeeds is now `completed`, and `surfacedToolFailures` carries the recovered-from failures so the Evals console can honestly show "green run with hidden tool failures." Source: `cli/src/lib/traces/sync.ts`.
