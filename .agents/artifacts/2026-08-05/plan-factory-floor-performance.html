Purpose

Factory Floor paid a constant cost for feeling "live": a 3-second local fetchLocalSessions interval, a 45-second remote SSH fan-out, and a 140ms React throughput timer. The first paint waited on host sync, so operators saw a blank or blocking canvas while last-good data already existed on the host. This plan is the UI track of issue #2030: render cached rows immediately, expose freshness + manual refresh, and drop duplicate chrome — without changing extension-host command semantics or touching apps/cli/** / apps/factory/src/vscode/**.

Sibling tracking for DotAgents layout canonicalization: #2006.

Public Interface

No new CLI flags or extension-host commands. The webview continues to post the same messages; only when it posts them changes (one-shot + manual, not intervals).

Risks

Risk Mitigation

Load-bearing takeaway: Factory Floor is a thin read-only consumer — never a second scheduler. Cached rows always win over a blank syncing canvas; remote fleet cost is opt-in via the freshness chip.
