- **`agents pr land <number>` — standalone merge-on-green command (RUSH-2296).** A new `agents pr` command group with one subcommand: `land`. It watches a single PR through CI and a non-author review, then rebase-merges on green — without `--admin` and without bypassing branch protection. Built on the `pollPrSnapshot` and `isFailedCheck` primitives from the existing `teams pr-watch` machinery so check-state logic is not duplicated. CI failures surface as a loud non-zero exit with the failing check name rather than silently merging or retrying. Non-author approval is verified via the GitHub Reviews REST endpoint (not GraphQL). Rate-limit guidance applies: do not run two `pr land` calls against the same PR concurrently. Source: `apps/cli/src/commands/pr.ts`.
