- **Reserve the `auth` secrets bundle as file-backed (PHNX-2365 / SEC-GAP-3).**
  `agents secrets create/import auth` now forces the file backend and fails
  loud on keychain or vault, instead of letting a keychain-backed `auth`
  bundle be silently ignored by usage/probe. `resolveClaudeSetupToken` throws
  the same error rather than returning null, and `agents doctor` emits
  `auth-bundle-wrong-backend`. Source: `cli/src/lib/secrets/bundles.ts`,
  `cli/src/lib/claude-account-token.ts`.
