- **Interactive `agents run` now spawns directly by default (RUSH-3066).** `tmux.enabled` is an explicit per-device opt-in for addressable panes instead of the default wrapper. `--no-tmux` and `--disable-tmux` remain compatible no-ops while wrapping is off. A direct launch with no precise tmux, iTerm, editor-terminal, or pty rail prints one line naming that `agents message`, injection, and `agents focus` are unavailable and shows the config command that restores them.
