- **`agents permissions add ~/.config/opencode/opencode.json` now imports instead of printing "No permission sets found" (RUSH-2702).** Harness detection built its match suffixes by calling each registry target's `home('')`, and OpenCode's entry probes the filesystem to choose between the two spellings OpenCode accepts (`opencode.jsonc` / `opencode.json`). With an empty root that probe resolved against `process.cwd()`, so the same file detected differently depending on where the CLI happened to be run. Detection now reads an explicit `altSuffixes` list covering **both** spellings OpenCode accepts, so no detection candidate comes from a filesystem probe; resolving a real root still probes, which is correct there. Regression-tested for each spelling from a cwd carrying decoy configs and from a bare one — the decoy cwd is what reproduces the bug, which is why single-cwd coverage passed before.
