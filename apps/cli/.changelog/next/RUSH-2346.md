- **`agents --help` / `--version` no longer run the macOS menu-bar self-heal (RUSH-2346).** On darwin the startup self-heal (`installMenubarLaunchAgentOnUpgrade()`) ran on every invocation, including the pure documentation paths, dynamically importing `lib/menubar/install-menubar.js` and doing its filesystem checks before deciding to no-op. It now carries the same `helpOrVersionRequested` gate the update check, background sync, and `ensureInitialized` already use, so help and version output skip it entirely. Source: `apps/cli/src/index.ts`.
