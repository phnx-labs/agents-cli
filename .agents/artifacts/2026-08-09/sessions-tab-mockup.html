A Sessions tab that recovers your work

You run hundreds of sessions across projects. The machine sleeps, reboots, or drops off Tailscale, and those sessions become orphaned (alive but detached) or crashed. The Sessions tab is the one place to see every session you own — local and remote, active and orphaned — and resume any of them in one click, or a whole project's worth at once. It reads the roster Factory already polls, filters entirely client‑side, and virtualizes the list, so hundreds of rows stay instant.

  • Star — click ☆ on any row; it pins to the Starred band and persists (globalState, like host pins). A pure UI preference — no fleet action, so it's safe under Factory's "no second scheduler" rule.
  • Resume — one click routes to the session's owning machine via agents sessions resume <id> (remote sessions get the remote badge and --host automatically). Multi‑select → resume a whole project's worth after a reboot.
  • Orphaned + crashed float up under “Needs reconnecting” — the exact set you lost when the machine went off, with Resume‑all.
  • No slowdown — reads the roster Factory already polls (agents sessions --active --json); every filter/sort/group is client‑side; the list is virtualized so 221 rows render like 20.
