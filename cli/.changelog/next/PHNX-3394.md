- **The system DotAgents repo is now `phnx-labs/.agents` (renamed from `.agents-system`), and the old name still resolves (PHNX-3394).** The `-system` suffix was redundant once the layering itself is the role, so the canonical clone target is now `gh:phnx-labs/.agents`. This is additive back-compat, not a cutover: every existing fleet checkout points at the old remote, so both names are recognized as the system origin across all transport forms (ssh / https / scp-style). Recognition is centralized — `SYSTEM_REPO_SLUGS` in `types.ts`, a `RENAMED_REMOTE_ALIASES` fold in `canonicalGitRemote` so the two names compare equal everywhere (`sameGitRemote`, repo adoption, the DotAgents-layer classifier), and a pure `isSystemRepoRemote` behind `isSystemRepoOrigin`. The companion extras repo `phnx-labs/.agents-extras` keeps its name but is now private and opt-in (`agents repo add`, not cloned by default). Source: `cli/src/lib/{types,git,state}.ts`.
