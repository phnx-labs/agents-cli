- **Rush Cloud no longer reads the interactive Claude login when building account credentials — it now reads only the file-based `agents secrets` setup-token (RUSH-2359 / incident #1767).** `readClaudeCredentialsBlob` previously called `loadClaudeOauth(home)` without options on macOS (interactive Keychain login) and read `.credentials.json` raw on Linux. Both are rotating OAuth tokens the Rush server must not hold. The fix passes `{ accessTokenCache: true }` and rejects anything that is not a clean `sk-ant-oat01-*` setup-token. Source: `apps/cli/src/lib/cloud/rush.ts`.
