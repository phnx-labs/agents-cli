01The context boundary

Bare /recap remains an end-of-session report. A non-empty selector switches to historical mode and uses agents sessions to locate the source.

invariantThe new agent receives a new session ID and a structured recap. It does not resume the source, inherit its ID, continue pending work, or treat historical state as current.
