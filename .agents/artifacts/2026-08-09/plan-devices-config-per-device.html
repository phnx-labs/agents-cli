Device config lives per-device again — with the pin churn root cause fixed

User direction: per-device config belongs at ~/.agents/devices/<name>/ (conflict-free by construction); all-devices config belongs in central agents.yaml. This reverses #2458's central-block storage and fixes the real reason devices/ was gitignored — the auto-written agent pins, not operator config, caused the churn. Pins move to untracked runtime state, the per-device doc becomes operator-config-only and syncs again.

Purpose

Three kinds of state were sharing homes badly. Split them so each lives where its write pattern belongs:

The `agents devices config` command — key-value, TTY menu, --json, tombstones — ships unchanged from #2458. This PR moves only the storage backend and adds `--fleet` for the all-devices layer.
