Plan: Unified agents config Command Barrel

Purpose

Replace the fragmented configuration surface of agents-cli — agents defaults run, agents models tier, agents devices set-interactive, agents browser profiles set-default, and agents devices configure — with a single agents config namespace. Every agent/harness reference must use agent@version, and tier overrides must fold into the run-time configuration namespace because tiers are part of how an agent runs.

This plan proposes a facade-only change: the YAML storage stays the same; only the CLI surface is consolidated.

This forces users to remember which subsystem owns each knob.

Proposed Changes

Add agents config list|get|set|unset as the one barrel. The new command translates dotted keys into the existing YAML stores. The old commands remain as thin aliases that print deprecation warnings.

New files:

  • apps/cli/src/lib/config-keys.ts — parser and registry for the key grammar.
  • apps/cli/src/commands/config.ts — registers and implements the command.
  • apps/cli/src/lib/config-keys.test.ts — unit tests for the parser.
  • apps/cli/src/commands/config.test.ts — integration tests for the command.

Modified files:

  • apps/cli/src/lib/startup/command-registry.ts — add config loader.
  • apps/cli/src/lib/run-defaults.ts — add helper setters used by the new command.
  • apps/cli/src/lib/model-tier-overrides.ts — add helper setters used by the new command.
  • apps/cli/src/commands/defaults.ts — delegate to agents config.
  • apps/cli/src/commands/models.ts — delegate tier subcommand to agents config.
  • apps/cli/src/commands/ssh.ts — delegate configure and set-interactive to agents config.
  • apps/cli/src/commands/browser.ts — delegate profiles set-default to agents config.
  • apps/cli/AGENTS.md, apps/cli/README.md, openspec/specs/configuration-surface/spec.md — docs.

Examples

# Default model/tier for all Claude versions
agents config set run.claude@*.model best
agents config set run.claude@*.model claude-opus-4-8

# Define what each tier resolves to
agents config set run.claude@*.tier.best claude-opus-4-8
agents config set run.claude@*.tier.default claude-sonnet-5
agents config set run.claude@*.tier.cheap claude-haiku-4-5

# Other run-time defaults
agents config set run.claude@*.mode auto
agents config set run.claude@*.effort high

# Central and device config
agents config set interactive.host workstation
agents config set browser.profile work
agents config set devices.release-host.max-agents 4
agents config list
agents config get run.claude@*.model
agents config unset run.claude@*.tier.best

Risks

Risk Mitigation
Old commands break Keep them as aliases with deprecation warnings; existing tests guard behavior.
Key grammar is ambiguous Strict parser: agent id must be in AGENTS, version must match VERSION_RE, tier must be one of MODEL_TIERS.
Project-local overrides surprise users agents config list shows the effective value and its source (user / project file path).
Mixed-version fleet sees old YAML only Storage does not change, so old CLIs continue to read the same data.
