- **Managed-share OG cards stop 500ing on ordinary titles and non-HTML artifacts (PHNX-3386).** The card renderer uses Latin-subset Inter/JetBrains fonts, and satori throws on the first glyph they lack — so a title with an em-dash, curly quotes, or the ellipsis a truncated description ends with crashed the whole `<slug>.png` render into a 500. Titles/descriptions are now sanitized (common typographic punctuation mapped to ASCII; anything still uncovered dropped) before rendering, so the card renders instead of failing. Separately, a published **non-HTML** artifact (e.g. an image) no longer has its raw bytes regex-scanned into a garbage description — the cover route only derives title/description from `text/html` bodies. Real-workerd regression tests cover an em-dash/ellipsis/emoji title and an image artifact. Source: `cli/src/lib/share/worker-template.ts`.
