- **Cap fleet-wide Linear API spend with a shared per-key request budget (PHNX-2310).** With ~13 concurrent drain agents on one Linear API key, nothing stopped them collectively exhausting Linear's 2,500 requests/hour limit and throttling ticket-status reads fleet-wide. The `agents projects` card fetch now reserves against a proactive, cross-process budget keyed by the API key before each request; when the hourly pool is spent it serves the last cached snapshot (marked stale) instead of forcing a 429. This complements the existing read cache and reactive 429 backoff — the pool is lock-free on-disk state (one stamp file per request, a sliding one-hour window), so N separate agent processes coordinate without a shared mutable document to race on. Source: `cli/src/lib/linear-rate-limit.ts`, `cli/src/lib/linear-project-counts.ts`.
