04--device routing

The browser already scopes its fan-out to named hosts and --active --device X already opens it. Only one early return stands in the way.

The extracted predicate must add three conditions the current inline version lacks:

  • process.env.AGENTS_SESSIONS_LOCAL !== '1' — the peer-side recursion guard. The --active gate checks it (:1259); the bare gate relies on the implicit invariant that peers are always invoked with --json. Make it explicit.
  • !options.cloud — :1220 currently returns before the cloud branch at :1284. Once --device falls through, --device box --cloud would reach runCloudSessions, which ignores the host scope.
  • (options.host?.length ?? 0) <= 1 — see the multi-host row below.

bareBrowserSeed (sessions-browser.ts:163) gains host?: string[] and must force projectScope: 'all' whenever a host scope is present: applyFilters filters on r.cwd.startsWith(process.cwd() + '/') (:355-358) and no peer cwd matches, so the 'repo' default would render an empty list. Make the p hotkey (:487) a no-op under a host scope — returning the same reference is already a no-op (picker.ts:617).

06Rejected: recording the orchestrator on the team registry

Recorded so it isn't re-proposed. The obvious approach is TeamMeta.spawned_by_session plus a one-time backfill from teammate meta.json files. Three disqualifiers.

PropertyRegistry + backfillDB column
Survives GC no teammate dirs are deleted after 7 days (teams/agents.ts:1464-1467, cleanupAgeDays = 7 at :1364) — a backfill writing null for older teams freezes the wrong answer permanently yes the transcript is the source; a rescan re-derives it
Crosses the SSH hop no registry.json is per-machine under .history/ (registry.ts:4-8) — it cannot resolve a peer's orchestrator, and post-§04 the browser is explicitly cross-machine yes serializeSessionsJson strips only _matchedTerms/_bm25Score/_remote (sessions.ts:842-843)
Complete coverage no AGENTS_SESSION_ID is pre-minted only for Claude via agents run (exec.ts:1389-1391) — a human typing agents teams create, or any Codex/Grok/Gemini orchestrator, records nothing yes reads the command off the transcript, harness-agnostic
Read cost on the listing path high a JSON read plus a cross-process lock write (registry.ts:82-85) on a path the browser re-runs per hotkey zero one more column in a row already SELECTed
