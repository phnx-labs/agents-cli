- **`sessions resume <ag-…> --attach-only` attaches a live local tmux pane before any fleet SSH (PHNX-3292).**
  `sessions focus` already knew how to attach a live `ag-<agent>-<8hex>` alias
  by name, but it ran that attach *after* `collectSessionCandidates` — two SSH
  fan-outs that stalled ~2 minutes on offline devices (measured on yosemite-s0
  for `ag-claude-0145ab8f`) and printed the skip list twice. An alive local
  pane is now attached immediately; `--device` still sweeps. Source:
  `cli/src/commands/focus.ts`.
