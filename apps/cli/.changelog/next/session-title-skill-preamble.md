- **The recap ladder no longer titles a skill-launched session after the skill's install path.** `deriveSessionRecap` cleaned the first-prompt `topic` through `classifyUserPrompt` but took the `label` rung raw, so a harness that auto-names a session from a first turn opening with a skill produced the derived title `Base directory for this skill: /home/…/.claude/skills/continue` — permanently, since `label` is the top rung and always wins. The label now goes through the same classifier and collapses to `/<skill>` when — and only when — the classifier reports the injected `Base directory for this skill:` line; a deliberate `/rename` label is still shown verbatim, including one that merely mentions a `skills/…` path. This fixes the derived `ActiveSession.title` (the `agents feed watch` / `agents sessions watch` streams and the AGI EXT Fleet row). Surfaces that render the raw `SessionMeta.label` instead of the derived title — the interactive `agents sessions` preview header and `--flat` / `--tree` — are unchanged here and tracked in RUSH-3117. Source: `apps/cli/src/lib/session/active.ts` (`deriveSessionRecap`).
