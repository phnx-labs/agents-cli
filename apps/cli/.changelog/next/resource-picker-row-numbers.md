- **Resource pickers number their rows.** The interactive lists behind `agents inspect <repo> --commands` (and the other resource views built on the same picker — plugins, skills, hooks) prefix every row with its position in the filtered list (` 1.` … `12.`), right-aligned so labels stay columnar. The header already showed the total (`commands (12)`); the row numbers say where each entry sits in that count while scrolling. Filtering renumbers from 1 over the matches. Source: `apps/cli/src/lib/picker.ts` (`PickerConfig.numbered`), `apps/cli/src/commands/resource-view.ts`.
