Purpose

The current footer presents f favorites and * star, which looks like two features even though both use one favorite store. The intended surface has one bookmark concept and two distinct navigation actions: Enter resumes the highlighted session, while F focuses it.

Load-bearing decision: F must submit the highlighted row as a focus action and then enter the canonical focus implementation. It must not reproduce tmux, SSH, or recovery logic inside the picker.

Public Interface

The old and new public forms are intentionally not aliases:

agents sessions bookmark <id>
agents sessions bookmark --list --json   # { "bookmarks": [...] }
agents sessions --bookmarks
agents sessions focus --bookmarks

Picker navigation:
b / B   filter to bookmarks
*       toggle bookmark on highlighted row
f / F   focus highlighted row
Enter   resume highlighted row
