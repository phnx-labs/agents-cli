Sort agents view accounts by email

Keep the selected default account first, then make the remaining managed agent accounts scannable by sorting email-bearing rows alphabetically. Preserve the existing machine-readable JSON order.

The current human renderer sorts non-default rows by semantic version descending.·Account information is already loaded before the renderer sorts rows.

Purpose

When a user runs agents view claude, the selected default stays at the top, but every other account currently follows version order. The same shared renderer controls all managed native agents, so the fix belongs in that renderer rather than in Claude-specific code.

Behavior: default first; email-bearing accounts A–Z; rows without email last in version-descending order.

Proposed Changes

Area Change Compatibility
Human renderer Add a pure comparator and sort after account data is loaded Changes only row order
JSON renderer Keep default-then-version sorting No machine-output change
Tests Cover precedence, email order, missing emails, and the real CLI Prevents regression

Public Interface

No flags, configuration keys, or types change. These commands gain the new human ordering:

Risks

Risk Handling
