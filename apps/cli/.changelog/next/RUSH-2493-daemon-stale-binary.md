- **`agents daemon status` now reports a daemon running code that has been deleted (RUSH-2493).** A daemon keeps running from memory after its entry file is removed — so it answers every probe, `systemctl --user is-active` reads `active`, and the status command reported healthy, while the process cannot restart and is executing whatever was loaded before the delete. Observed on a dev box: a daemon ran 4h14m from a worktree that had been deleted, silently holding a second routine scheduler (the double-fire class the one-scheduler-one-executor rule exists to prevent), and nothing anywhere named it. `status` now carries a `Stale code` section listing each such pid with its missing entry, marks the `Binary:` line `(MISSING from disk)` when it is this device's own daemon, and `daemon doctor` counts it as a problem with the right remediation per case — `agents daemon restart` for your own, `kill <pid>` for a stray from a removed install or worktree. `--json` gains `binaryMissing` and `staleBinaries`. Three deliberate limits keep it from accusing a healthy daemon: it reports only a **provable `ENOENT`** (`statSync` with `throwIfNoEntry`, since `existsSync` returns false for a permission error too — a root-owned daemon under an unreadable parent would otherwise be named, with a `kill` that could only `EPERM`); it is scoped to **this install's instance registry** plus this device's own daemon, the same scope RUSH-2368 established for duplicates, so a leaked test orphan can never make `daemon doctor` exit 1 for everyone on the box; and it considers **absolute entry paths only**, so `node -e '<code>' __daemon-run` is never mistaken for deleted code. That last guard also exempts entry paths containing spaces, which `ps` renders unquoted — a healthy daemon on such a path is never accused, at the cost of not detecting a genuinely deleted one. Detecting an *untracked* `__daemon-run` process — the second signal named on RUSH-2493 — is deliberately not included, because it is precisely the box-wide scope RUSH-2368 removed; the ticket stays open for it.
