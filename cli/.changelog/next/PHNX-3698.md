An important/`--blocked` post (and an owner send) also fires a best-effort, opt-in background `agents traces sync` so the linked console page exists when tapped (gated exactly like the run-exit arm; `AGENTS_NO_TRACE_SYNC=1` opts out). The Linear-key detector is now canonical in one place shared with transcript ticket detection (`session/linear.ts`).
