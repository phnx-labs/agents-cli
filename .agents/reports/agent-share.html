01Why now — a deadline, not a hunch

The EU AI Act's high-risk obligations became fully enforceable Aug 2, 2026 (penalties to €15M / 3% of turnover). Auditors now ask for per-commit provenance of AI-written code — and the single most-cited gap is that git history shows the human who committed the code, not the agent that wrote it, or why.

what real devs actually say On accountability: "there must be accountability — nothing merged without human review." On signing: "almost nobody uses [commit signing]," "I'm giving up on PGP." The lesson: the pain is real, but the client must be zero-friction and automatic — nobody will hand-sign commits. (HN, 2025–26.)

04How it works — three layers that compose

Signing proves who. Attestation carries what. Only binding the session carries why — the auditor's real ask. Agent Share is the why layer, hardened by the other two.

LayerAnswersBuilt on
1 · signwho / what produced itkeyless gitsign / Sigstore + OIDC or SPIFFE workload identity — no keys to manage (nobody adopts key friction)
2 · atteststructured facts on the committrailers: Assisted-by: (Linux-kernel convention) + Agent-Session: + Agent-Session-Hash:
3 · bind sessionwhy — the reasoningAgent Share: the commit points to the permissioned, signed session. This is the moat.
why this is defensible Layer 1 is being standardized into free tooling (Sigstore, the IETF identity-attributed-commits draft). Competing there loses. No one binds the full reasoning to the commit as a permissioned, shareable record — that's the gap, and it's exactly what auditors demand.

05How agents integrate — zero-friction first

Harness-agnostic: it reads whatever transcript the agent already writes (Claude / Codex / Cursor JSONL). Three surfaces, one API.

defaultGit hook — installed once, fires on every agent commit. Auto-mints, stamps the trailer, gitsigns. The dev does nothing. This is the only mode that actually gets adopted.
ciGitHub Action — for cloud/headless agents. Uses the workflow's OIDC identity for keyless signing (no secrets).
manualCLI — agent-share publish <session> for one-offs, backfills, or non-git surfaces.
 
# one-time, per repo or per machine
agent-share init          # installs the git hook, logs you in, enrolls a keyless signing id

# then it's automatic — the post-commit hook does this for you:
CARD=$(agent-share mint --session "$AGENT_SESSION_ID" --quiet)
git interpret-trailers --in-place \
  --trailer "Assisted-by: claude-opus-4.8 (agent)" \
  --trailer "Agent-Session: $CARD" \
  --trailer "Agent-Session-Hash: $(agent-share hash)"  "$1"
# commit is gitsigned with your OIDC identity → signature covers the trailers

Result on a public PR — a locator, not a secret:
