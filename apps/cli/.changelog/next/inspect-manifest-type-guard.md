- **`agents inspect` no longer crashes on a plugin whose `plugin.json` field types contradict the manifest interface.** `loadPluginManifest` casts parsed JSON straight to `PluginManifest` and validates only `name`/`version`, so any other field is whatever the file says. A `"dependencies": "some-plugin"` string reached `.join()` (truthy `.length`, no `.join`) and a bare numeric `"version": 2` reached `.split()`, both throwing inside `pluginToItem` — which runs while *building the plugin list*, so a single malformed manifest anywhere took down `agents inspect .`, `--plugins`, `--json`, and even a query for a different, valid plugin. Fields are now coerced or dropped rather than trusted, and the row renderer coerces defensively so no future manifest field can crash it. Source: `apps/cli/src/commands/inspect.ts`.
