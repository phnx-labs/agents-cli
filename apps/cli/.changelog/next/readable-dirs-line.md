- **Readable `Dirs:` line in `agents sessions`.** The session preview's touched-directories line no longer renders raw Claude project-slugs (`-Users-me-src-…`) or nested worktree paths. Paths under a git worktree collapse to `⧉ <slug>/<remainder>`, Claude-encoded slugs are decoded back to a real path before relativizing, and paths still relativize against the session cwd and home (`~`). Source: `apps/cli/src/commands/sessions-picker.ts`.
