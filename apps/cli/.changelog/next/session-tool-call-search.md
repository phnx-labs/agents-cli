- **`agents sessions` can query distinct tool calls in the same session, locally or across the fleet.** Use `--include tools`, repeat `--query` with `tool:`, `program:`, `input:`, `output:`, `status:`, `exit:`, or `error:` fields, and add `--fleet` for live SSH fan-out. Each device keeps a redacted, bounded SQLite/FTS cache; unchanged transcripts are not reparsed, peer responses are size-limited and validated, and terminal controls are removed. A sampling script extracts redacted shell-command origins from 50–100 sessions over the last seven days into an explicitly truncated, 16 MiB maximum artifact.
