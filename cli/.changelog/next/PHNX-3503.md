- **`agents worktree list|done|sweep` reclaims PR-bound worktrees (PHNX-3503).** Worktree law created a checkout per change and nothing ever removed it — `gh pr merge --delete-branch` drops the branch and leaves the tree — so merged worktrees accumulated until a box ran out of disk (581 worktrees / ~263 GB measured across the fleet; the release home base wedged at 1.6 GiB free, PHNX-3478). `sweep` removes a worktree **and** its branch only when the tree is clean, nothing is missing upstream, it is not the primary checkout, and it is past the grace window (default 3 days; `done` is immediate and attended). Merge is judged by **patch-id** (`git cherry`), not ancestry, so a squash- or rebase-merged branch counts as landed even though its SHAs were rewritten — an ancestry check reports "unmerged" for a branch that fully merged. Every check fails closed: an undeterminable answer holds the worktree instead of removing it. This is the only surface that may delete a branch; agents keep no `git branch -d/-D` permission, because the authority here is the merge, not the caller.
