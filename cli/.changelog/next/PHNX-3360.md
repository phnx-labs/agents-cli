- **`agents insights output --json` and `agents insights cost --json` now honor every flag (PHNX-3360).** `--json`, `--since`, and `--by` share their long names with the `insights` parent command, so commander bound them to the parent at parse time and the `output`/`cost` leaves — which read their own `opts()` — never saw them: `--json` printed the human table (invalid for machine callers), `--by` fell back to the default agent grouping, and `--since` was ignored (7d default). Both actions now read `command.optsWithGlobals()`, matching the sibling `insights mix` recipes. Unblocks the `yc:workweave` shipped-output engine, which shells `agents insights output --by project --json`. Source: `cli/src/commands/output.ts`, `cli/src/commands/cost.ts`.
