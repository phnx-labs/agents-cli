- **`agents inspect` no longer crashes on a plugin whose `plugin.json` field types contradict the manifest interface.** `loadPluginManifest` casts parsed JSON straight to `PluginManifest` and validates only `name`/`version`, so any other field is whatever the file says. A `"dependencies": "some-plugin"` string reached `.join()` (truthy `.length`, no `.join`), a bare numeric `"version": 2` reached `.split()`, and a non-string `"description"` reached `.split()`/`truncateToWidth` — each throwing while *building the plugin list*, so a single malformed manifest anywhere took down `agents inspect .`, `--plugins`, `--json`, and even a query for a different, valid plugin. Every manifest field the view reads is now coerced through one helper, and an object or array renders as an omitted row rather than `[object Object]`. Source: `apps/cli/src/commands/inspect.ts`.
