- **The traces insight-engine fingerprint now folds in the session failure phenotype (PHNX-3327).** `computeInsights()` groups failure patterns by `(tool, cause, normalized-error, phenotype)`; the phenotype (false-termination / premature-completion / out-of-order / failure-to-act from `phenotype.ts`) is computed from the same `SessionDetail` built during per-session upload, so the index shard stays incremental and does not re-parse transcripts at scale. Existing patterns with no phenotype remain stable. Source: `cli/src/lib/traces/insights.ts`, `cli/src/lib/traces/sync.ts`.
