- **A session launched with a skill no longer titles itself after the skill's install path.** A harness that auto-names a session from its first turn named it after the injected scaffolding when that turn opened a skill, so `agents sessions` and the AGI EXT Fleet showed `Base directory for this skill: /home/…/versions/claude/2.1.207/home/.claude/skills/continue` where the task belongs — for the whole life of the session, since the `label` rung of the recap ladder always wins. `deriveSessionRecap` cleaned the first-prompt `topic` through `classifyUserPrompt` but took `label` raw; it now runs the label through the same classifier and collapses it to `/<skill>` when — and only when — the classifier reports the injected `Base directory for this skill:` line. A deliberate `/rename` label is still shown verbatim, including one that merely mentions a `skills/…` path. Source: `apps/cli/src/lib/session/active.ts` (`deriveSessionRecap`).
